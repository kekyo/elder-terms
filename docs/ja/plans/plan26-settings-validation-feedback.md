# plan26：設定項目ごとの検証エラー表示

状態：完了。全体試験とWin11のSMB2/3回帰試験が成功しました。SMB1の実機試験は、利用者の指示により保留中です。

## 目的と範囲

設定を適用できないとき、修正する項目と理由を画面で分かるようにします。接続設定、グローバル既定値、アプリケーション設定を対象とし、入力欄だけでなく選択欄、キーバインド、マクロ、リンク規則にも共通の表示を使います。

利用者は提案した表示方針を承認しました。INIを直接編集して矛盾した設定にした場合の実行時対策は、今回の対象外です。既存の入力検証を画面へ結び付け、実行時の検証を新設することはしません。

## 表示と操作

テキスト入力欄にはGTK3の`.error`スタイルと標準エラーアイコンを使います。枠や色はテーマに従います。選択欄などにもエラーアイコンを添え、欄全体のホバーで理由と修正方法を表示する方針です。通常時の説明は、エラーが解消したら元に戻します。[GtkEntryのスタイル](https://docs.gtk.org/gtk3/class.Entry.html#css-nodes)と[標準ツールチップ](https://docs.gtk.org/gtk3/method.Widget.set_tooltip_text.html)を参照しました。

エラーのあるタブにも印を付け、別タブの問題で適用できない場合に場所が分かるようにします。色だけに依存せず、アイコンと文章を併用します。修正のたびに表示を更新し、入力エラーがすべて解消すると適用・保存を可能にします。

空欄が継承を意味する場合は、継承後の値で判定します。必須でない空欄や、グローバル既定値で未指定を許す項目は、新たな必須項目にしません。非表示の接続方式や無効な機能の扱いも、既存の適用条件に合わせます。

SMB1でSSH Proxyの「有効」を選ぶと、その選択欄にエラーを表示します。説明は「SMB1ではSSH Proxyを利用できません。SMB2/3へ変更するか、SSH Proxyを無効にしてください」です。選択値は編集中の値として保持し、適用・保存を止めます。Proxyが有効な状態でSMB1へ切り替えた場合や、継承値による組み合わせも同様です。SMBの版やProxyを修正すると、関連項目とタブの表示を同時に更新します。

## 現在の実装と変更方針

`settings-widget.cpp`には入力欄のエラークラスとアイコンを設定する処理があります。ただしツールチップはアイコンに限られ、分割された各設定エディターには別の表示処理があります。必須項目や項目間の矛盾は、対象欄と対応付かない文字列として返されることがあります。

検証結果には対象項目と理由を持たせ、同じ結果から欄の表示と適用可否を更新します。文章の解析で設定項目を推定する方式は採りません。マクロやリンク規則は対象行・編集欄まで示し、現在選択していない規則のエラーも見つけられるようにします。
