# SMBの使用

SMBは、WindowsやSambaが公開する共有フォルダーに接続する方式です。elder-termsはSMB2/3でサーバーのTCPポートへ接続します。直接接続のほか、experimental機能としてSSH proxyを経由できます。GVfsは使用しません。サーバー側で共有と利用者のアクセス権を用意してください。

## 接続する

ランチャーで接続を作成し、接続種別を「SMB」にします。SMBタブにサーバーのアドレスと共有名を入力して保存してください。共有名には、サーバーが公開している一つの名前を指定します。`\\server\share`のようなパス全体は入力しません。

接続には、ユーザー名とパスワードを使うNTLM認証を使用します。ウィンドウを開くと、ユーザー名とパスワードを順に尋ねます。ユーザー名の初期値は設定した名前です。設定が空なら現在のOSユーザー名を表示します。ドメインを指定した場合は、その値を認証に使います。パスワードは接続のたびに入力し、設定ファイルへ保存しません。

接続後は、左右にローカルと共有フォルダーを並べて表示します。項目を選んで右クリックすると、ファイルやフォルダーの送受信、名前変更、削除、新しいフォルダーの作成ができます。フォルダーの送受信と削除は、その中の項目も対象です。同名の転送先があるときは、上書きするか、飛ばすかを選べます。

通信が切れた場合は、ウィンドウの「再接続」を選んでください。通信中の操作を取り消した後も、再接続が必要になることがあります。接続が切れた操作を自動で繰り返すことはありません。再接続後に一覧を更新し、サーバー側の結果を確かめてから操作してください。

## 設定項目

接続の設定は`[smb]`に保存します。接続ごとの値は「接続の既定値」から継承できます。

| 項目・INIキー | 既定値 | 指定方法 |
| --- | --- | --- |
| アドレス `address` | 空 | ホスト名、IPv4、IPv6。接続時に必須。 |
| ポート `port` | `445` | SMBサーバーのTCPポート。1～65535。 |
| 共有名 `share` | 空 | パス区切りを含まない一つの共有名。接続時に必須。 |
| ドメイン `domain` | 空 | NTLM認証のドメイン。空ならドメインを指定しない。 |
| ユーザー名 `username` | 空 | 認証画面に表示する初期値。 |
| ローカルディレクトリ `local_directory` | 空 | 左側の初期ディレクトリ。空なら共通の転送先設定を使用。 |
| リモートディレクトリ `remote_directory` | `/` | 共有内で最初に表示する絶対パス。 |
| 署名を必須にする `require_signing` | `true` | SMBメッセージの署名を必須にする。 |
| 暗号化を必須にする `require_encryption` | `false` | `true`なら暗号化できない接続を拒否する。`false`でもサーバーが暗号化を要求する接続は使用できる。 |
| 接続タイムアウト `connect_timeout_seconds` | `30` | SMB接続を待つ秒数。SSH踏み台への接続・認証には適用しない。1～86400。 |
| 無通信タイムアウト `idle_timeout_seconds` | `60` | 通信が進まない状態を待つ秒数。1～86400。 |

次の例で最初に開くフォルダーは、共有内の`/Documents`です。パスワードは記録しません。

```ini
[general]
type=smb
name=Team files

[smb]
address=files.example.com
share=team
domain=OFFICE
username=alice
remote_directory=/Documents
require_signing=true
require_encryption=false
```

## SSH proxy経由の接続（experimental）

接続の「SSH proxy」タブで踏み台を有効にすると、踏み台からSMBタブで指定したサーバーとポートへTCP接続します。踏み台とSMB共有には別々に認証します。踏み台から共有サーバーへ到達でき、TCP転送が許可されている必要があります。設定方法は[SSH proxyの使用](ssh-proxy.md)を参照してください。

SSHによる暗号化は手元から踏み台までです。踏み台から共有サーバーまでの通信については、SMBタブの署名と暗号化の設定が適用されます。
SMBの接続タイムアウトは、踏み台への接続と認証を待つ間には適用されません。待機を中止する場合は、接続ウィンドウを閉じてください。

## ファイル操作の注意点

SMBの共有内では、更新日時を表示・設定できます。リモートのPOSIX権限、シンボリックリンク、リモートハッシュ計算は扱いません。共有内のリンクやWindowsのjunctionなど、別の場所へ移動する項目は追跡しません。

送信中は共有内に一時ファイルを作り、完了後に最終名へ変更します。通常の名前変更では、既存の同名項目を置き換えません。通信が切れ、サーバーで一時ファイルが作られたか分からない場合は、そのパスをエラーに表示します。所有を確認できない一時ファイルは自動削除しません。再接続して表示されたパスを確認し、不要であれば利用者が削除してください。

サーバーが読み取り専用にしている共有では、一覧と受信を利用できます。送信や変更を試みると、サーバーの拒否を表示します。
