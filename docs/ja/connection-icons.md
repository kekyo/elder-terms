# 接続アイコンの設定とドック連携

接続の「一般」タブで「アイコンを選択…」を開き、プリセットまたはPNG・JPEG画像を選びます。
アイコンは接続ごとの指定で、「接続の既定値」からは継承しません。

![プリセットと画像ファイルを選べる接続アイコンの選択画面](../../images/connection-icon-picker.png)

## 画像ファイルの条件

画像は元のパスから読み込みます。次回起動時も参照できる場所に置いてください。
ファイルと展開後のRGBA画像はそれぞれ64 MiB以内、各辺は16384画素以内です。
縦横比を保って正方形に収め、余白を透明にします。

画像を読み込めない場合は標準アイコンを表示し、接続はそのまま起動できます。
失敗理由は設定画面で確認してください。ファイルの欠落や未知のプリセットIDがあっても、保存した指定は自動では消えません。

## ドックでの表示

保存済みの同じ接続から開いたウインドウは、ドックで一つにまとまります。
接続名を変更した場合も同じグループですが、複製した接続は別のグループです。
未保存の編集内容で起動すると一時的な別グループになり、それをドックに固定して再起動するとランチャーが開きます。

ドックなどでの表示はデスクトップ環境に依存します。[GTKのアイコン仕様](https://docs.gtk.org/gtk3/method.Window.set_icon_list.html)を参照してください。
GNOMEでは、[キャッシュの更新](https://github.com/GNOME/gnome-shell/blob/46.0/src/shell-app-cache.c)を待つ間、数秒ほど以前の画像が表示される場合があります。
以前の画像が残る場合は、接続ウインドウを開き直してください。

ドック連携用のファイルは`$XDG_DATA_HOME/applications/`と`$XDG_DATA_HOME/icons/hicolor/256x256/apps/`へ保存します。
`XDG_DATA_HOME`が未指定なら、通常は`~/.local/share/`が保存先です。
ドックへの固定や実行中のウインドウでの表示を保つため、これらのファイルは接続の削除後も残ります。
削除済み接続の固定アイコンからは起動できません。不要になった固定アイコンはドックから外してください。

## INIでの指定

接続のINIファイルの`[general]`に`icon`を指定します。

| 値 | 画像 |
| --- | --- |
| `default`または省略 | elder-terms標準 |
| `noto:emoji_u1f44d` | Noto Color Emojiのプリセット例 |
| `material:action/home` | 黒い図柄と白い縁取りのMaterial Icons |
| `material:white:action/home` | 白い図柄と黒い縁取りのMaterial Icons |
| `file:/home/user/Pictures/server.png` | 絶対パスで指定したPNGまたはJPEG |

素材の出典は[素材とライセンス](connection-icon-artwork.md)を参照してください。
