# plan9：ブロックコピーの終端空白を除去する設定

作成日：2026年10月24日

## 目的と作業範囲

ブロックコピー時に、行末まで続く空白を除去するかどうかの設定を追加します。既定値は除去です。選択範囲の末尾が空白でも、その右側から行末までの間に文字がある場合は空白を保持します。

設定の保存とUIはelder-terms、終端空白の判定とコピー本文の生成はboxrigに置く構成を推奨します。本書は、その判断に至った分析、動作の定義、段階ごとの成果物と完了条件をまとめた計画です。初回保存時点では実装に着手していませんでした。後続の実装と検証は末尾の実施記録に記載します。

AGENTS.mdの外部コード変更禁止に合わせ、boxrig本体の拡張は上流側の別作業として扱います。elder-terms側の実装は、拡張済みの公開APIを利用できることが前提です。初回保存では製品コードと依存参照を変更しませんでした。その後、利用者からelder-terms側の実装と、boxrigの現在のdevelop HEADへのサブモジュール更新が明示的に指示されました。今回の実施範囲は段階2〜4のelder-terms側です。

## 用語と仕様上の前提

ブロック選択は、画面上の列をそろえて行ごとの矩形を選ぶ操作です。boxrigのAPIでは矩形選択と呼ばれます。通常選択は、本文の順序に沿って始点から終点までを選ぶ操作です。

本計画では、行を折り返し後の画面上の1行として扱います。これを物理行と呼びます。折り返し前の本文の1行である論理行とは区別し、終端空白の判定は物理行の右端までとします。履歴内の行も同じ扱いです。

コピー時点の本文を変更されない形で保持するデータを、スナップショットと呼びます。LFは改行を表す文字です。boxrigで本文を保持・処理する部分をcore、画面ごとの選択状態を持つ部分をビューと呼びます。

PRIMARYは選択完了時に登録し、中央ボタンで貼り付ける領域です。CLIPBOARDはCtrl＋Shift＋Cや右クリックの「コピー」で登録する領域です。今回の設定は、ブロック選択を両領域へコピーする際に共通で適用します。

終端空白の対象は、空セルと半角スペース単独（U+0020）とする案です。全角空白、改行を禁止する空白文字のNBSP、結合文字を伴う文字は保持します。行の単位と空白文字の範囲は、今回の依頼を具体化するために置いた仕様上の前提です。

boxrigの公式説明では、ブロック選択は表示列から本文の範囲へ対応付けられ、未表示の履歴でも全角文字や結合文字を分割せずに扱います。コピー結果は行内の論理順です。行の識別情報と内容の改訂を保持し、本文や文字配置が変わった選択は失効します。[公式説明][boxrig-text]、[公開APIコメント][boxrig-view]

現在の行別スナップショットAPIは、各出力行に少なくとも一つの空でない範囲を要求します。空白除去後に空になる行を扱うには、この表現も見直す必要があります。範囲を削除するだけでは、空行や行間の改行を失うためです。[coreのAPIコメント][boxrig-terminal]、[本文生成の実装][boxrig-core-text]

plan8では、ブロック内の末尾空白を保持する仕様を検証しました。本計画ではその動作を設定が無効な場合として残し、設定が有効な場合に終端空白の除去を追加します。

## elder-termsとboxrigの責務の比較

| 構成 | 実装上の性質 | 評価 |
| --- | --- | --- |
| elder-termsに判定と生成を集約する | コピー済みの文字列には、選択範囲の右側の情報がない。元のセル、履歴、表示列と文字の対応を別途追う処理が必要になる | 単純な文字列の末尾除去では要件を満たせず、既存の選択処理との重複が増える |
| boxrigで判定と生成を行い、elder-termsが設定する | 行情報、文字配置、選択の有効性、コピー容量の検査を既存処理と共有できる | 推奨する。上流の公開API拡張が前提になる |

コピー後の各行へ`trimEnd()`相当の処理を加えるだけでは、選択範囲外に文字がある場合の空白まで消してしまいます。画面に表示中の行だけを調べる方式では、未表示の履歴を含むブロック選択にも対応できません。

boxrig側にはビュー単位で「保持／行末空白を除去」を指定できる公開APIを追加します。elder-termsはその方針を明示的に設定し、製品の既定値として除去を選びます。公開APIの正式な名称と提供版は、上流側の実装時に確定します。

## コピー結果の定義

物理行の右端から連続する空白部分を求め、そのうちブロック選択に含まれる部分を出力から除きます。選択範囲の右側から行末までの間に文字があれば、選択範囲末尾の空白は保持します。

以下では`·`を空白、`[]`を選択範囲として示します。各例の末尾が物理行の右端です。

| 元の行と選択範囲 | 除去する場合 | 除去しない場合 |
| --- | --- | --- |
| `[abc··]····` | `abc` | `abc··` |
| `[abc··]··X·` | `abc··` | `abc··` |
| `[·····]····` | 空文字列 | `·····` |
| `[·····]··X·` | `·····` | `·····` |

行内の文字より前にある空白や、文字の間にある空白は保持します。除去対象は表示列に基づいて判定し、残る文字は既存どおり行内の論理順で出力します。全角文字、結合文字、複合絵文字を途中で分割したり重複させたりしません。

空白を除去して空になった行も、選択した行の一つとして残します。行間にはLFを一つずつ入れ、最後に余分なLFは加えません。例えば、2行目が空になる2行の選択結果は`abc\n`、3行とも空になる選択結果は`\n\n`です。最後の空行を表すLFは必要な行区切りです。

幅が正の有効な選択から空文字列が得られる場合も、有効なコピーとして扱います。幅ゼロの選択や、本文・文字配置の変更で失効した選択とは区別します。後者では既存のクリップボードを保持します。

設定は通常選択には適用しません。選択表示の範囲とコピー対象の範囲は分け、空白除去だけで矩形の表示や選択の始点・終点を変えない方針です。設定変更後も、同じ選択から新しい方針でコピーできるようにします。

## elder-termsの設定

設定キーは、`[terminal] block_copy_trim_trailing_spaces`とします。

| 項目 | 方針 |
| --- | --- |
| 型 | 真偽値 |
| 既定値 | `true` |
| キー未指定時 | 継承先に値があればその値を使い、最終的な既定値は`true` |
| `true` | 行末まで続く空白のうち、ブロック選択に含まれる部分を除去する |
| `false` | ブロック内の空欄と末尾空白を保持する |
| UIの配置と表示名 | 「端末」設定の「ブロックコピーの行末空白を除去」 |
| UIの操作 | 既存の真偽値設定と同じ継承、有効、無効の操作を使う |
| 適用の時点 | 起動時、起動中の設定変更、表示部品の再作成時 |

設定の保存・再読込では、明示的な`false`を未設定と区別します。リセットで明示値を解除した場合は、既存の継承規則に従って実効値を再計算します。

UIと利用者向け説明には、選択範囲の右側に文字がある場合は空白を保持することを記載します。日本語READMEを原本として英語READMEへ反映し、必要な翻訳文字列も更新します。
