# 文字選択とコピーの詳細

基本的な操作は[READMEの文字選択とコピー](../../README_ja.md#端末の文字選択とコピー)を参照してください。

## ドラッグ中の選択モード

左ボタンを押したときにCtrlが押されていれば、ブロック選択で開始します。
ドラッグ中は、Ctrlの変化を次のマウス移動で反映します。Ctrlありはブロック選択、Ctrlなしは通常選択です。
同じ文字の中での移動でも切り替わります。Ctrlの押下・解放だけ、ホイールや自動スクロール、左ボタンの解放では切り替わりません。

切替後も開始点は同じです。スクロールで開始点が画面外へ移動しても、元の文字から選択を続けます。
ダブルクリックから始めた通常選択は単語単位、トリプルクリックから始めた通常選択は行単位へ戻ります。
最初からCtrlを押して始めた選択の、通常選択への切替先は文字単位です。

切替だけではクリップボードを更新しません。左ボタンを離すと、最後に適用したモードで選択を完了します。

## クリップボード

選択完了時には、中央ボタンで貼り付ける選択クリップボード（PRIMARY）へ本文を登録します。
「コピー」やCtrl＋Shift＋Cで使う通常のクリップボード（CLIPBOARD）とは別です。
ESCや左クリックで選択を解除しても、登録済みの本文は消えません。

IMEで文字を変換している間は、ESCで変換を取り消し、次のESCで選択を解除します。
環境によってはIME側のキー操作が優先されます。[IBusのキー処理](https://github.com/ibus/ibus/blob/1.5.29/client/gtk2/ibusimcontext.c#L643-L752)を参照してください。

## ブロック選択のコピー結果

画面より長い履歴も選択でき、全角文字・結合文字・絵文字を分割せずにコピーします。
画面上の各行の間には、折り返し部分も含めて改行が入ります。最後に余分な改行は付けません。
双方向文字は行内の論理順でコピーします。

既定で除去するのは、画面上の各行の右端まで続く空白のうち、選択範囲内にある部分です。
選択範囲の右側に文字がある場合は、その手前の空白を保持します。
除去するのは空欄と半角スペース単独です。全角空白、改行しない空白文字（NBSP）、結合文字を伴うスペースは残ります。
空白除去で空になった行も、行として残します。

空白を保持したい場合は、「端末」タブの「ブロックコピーの行末空白を除去」を無効にしてください。
INIでの指定は次のとおりです。

```ini
[terminal]
block_copy_trim_trailing_spaces=false
```

組み込み既定値は`true`で、通常選択には影響しません。
設定を変更した後は、同じ選択から新しい設定でコピーし直せます。
PRIMARYとCLIPBOARDの両方に適用し、空白除去で本文が空になった場合もコピー先を更新します。

## 選択をコピーできない場合

幅がゼロの選択や、端末の出力更新で無効になった範囲はコピーできません。以前のクリップボードの内容は残ります。
選択やコピーが容量の上限を超えた場合も、途中までの本文では置き換えません。範囲を小さくして選び直してください。
フォーカス移動やメニュー表示、切断があると進行中のドラッグは終わりますが、完了済みの選択はフォーカス移動だけでは消えません。
