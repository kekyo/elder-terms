# plan16：HTTP/HTTPSによる簡易クローラ型ファイル受信

作成日：2026年11月2日

状態：計画作成。実装は未着手です。設定名と探索上限は初期案であり、段階1で実例を使って確定します。

## 目的と範囲

基準URLのHTMLに含まれるリンクから、ファイル転送画面に擬似的なディレクトリを表示します。対象は絶対URLと相対URLの両方です。基準URLの配下にあるリンクだけを残し、自己参照や循環リンクで探索が終わらなくなることを防ぎます。

HTTPとHTTPSは同じ転送方式の設定で選びます。HTMLの取得、一覧の閲覧、ファイルとディレクトリの受信を対象とし、書き込み操作は利用不可とします。WebDAVは既存の独立した方式として維持します。JavaScriptの実行、ログイン画面の操作、Webページの表示内容を再現する機能は含めません。

調査基準、実施手順、TDD、コミット、全体テストの条件は[plan15](plan15-transfer-jobs-and-tree-icons.md)の共通条件に従います。

共通HTTP層へ分離するのは通信、応答、TLS、認証、キャンセルです。WebDAV固有のXMLやパス規則は残します。URLの相対解決は[libcurlのURL API](https://curl.se/libcurl/c/libcurl-url.html)または既存GLibの公開URI APIを比較し、採用版のコメントを確認して一方に統一します。

[libxml2のHTML解析API](https://gnome.pages.gitlab.gnome.org/libxml2/html/HTMLparser_8h.html)は、ブラウザーのHTML5処理と同等ではありません。通常のディレクトリ一覧や単純なHTMLのリンクを対象に検証し、DOMの再現精度を完了条件にしません。

## 基準URLと探索範囲

URLの同一性と配下判定を、表示名やローカルパスから分離します。ここでオリジンはスキーム、ホスト、実効ポートの組です。ホストの大文字・小文字と省略された既定ポートを正規化し、HTTPとHTTPSは異なるオリジンとして扱います。

基準URLは配下を定めるディレクトリURLを基本とします。たとえば`https://host/pub/`で許可するのは`/pub/a.zip`などです。`/public/a.zip`、`/other/`、別ホストは除外します。判定にはパス区切りを含む境界を使います。

`https://host/pub/index.html`を開始ページにしたい場合の推奨案は、基準URL`https://host/pub/`と開始ページURLを分ける設定です。開始ページは基準URL配下に限定し、省略時は基準URL自身を取得します。ファイル形式のURLから親ディレクトリへ許可範囲を自動で広げる仕様にはしません。段階1ではこの二項目の操作を確認し、基準URL一項目だけにする場合の制限も明記して決定します。

| 入力・応答 | 扱い |
| --- | --- |
| 絶対URL、`/pub/a`、`a`、`../a`、`//host/pub/a` | 現在のページの最終URLを基準に解決し、その後でオリジンと配下を再検査する |
| `<base href>` | 解決基準に反映するが、許可範囲は設定済みの基準URLのままにする |
| HTML実体参照 | HTML解析で復元してからURLとして扱う |
| `.`、`..`、パーセント表記 | 一貫した正規化で比較する。区切りや親移動の解釈が曖昧な入力は除外し、二重デコードしない |
| `#fragment` | リソースの同一性と通信先から除く。同じページ内のリンクは新しい子ノードにしない |
| `?query` | リソースの識別情報として保持する。順序の変更や無条件の削除は行わない |
| HTTPの3xx | `Location`を一段ずつ解決・検証する。範囲外には接続せず、循環と回数超過を終了理由として示す |
| `mailto:`、`javascript:`、`data:`など | HTTP/HTTPS以外は転送ツリーに含めない |

相対参照と正規化の根拠は[RFC 3986の5・6節](https://www.rfc-editor.org/rfc/rfc3986.html#section-5)です。URLの解析と送信で異なる解釈を使わないことを、通信先を記録する試験サーバーで検証します。

## 擬似ディレクトリと循環の扱い

`a href`から得たURLをノード候補にします。ディレクトリ候補は、パスの末尾が`/`のURLです。展開時にHTMLを取得します。HTMLという理由だけで、すべての`.html`ファイルをディレクトリに変更しません。通常ファイルとしても保存できる構成です。

深いパスへの直接リンクでは、中間のディレクトリを擬似ノードとして表示します。リンクから判明した子を保持し、そのURLに一覧ページがなくても既知の子を閲覧・受信できる構成です。ディレクトリ候補が非HTMLだった場合はファイルへ分類し直し、曖昧な応答を空のディレクトリと断定しません。

探索中の祖先URL、取得済みページの集合、転送済みリソースの集合を分けます。祖先へ戻る辺はツリーから除き、一つの再帰受信で同じページを再取得しません。別の枝や利用者の再訪まで永久に禁止しないよう、訪問済み集合は探索・ジョブ単位で管理します。リダイレクト元と最終URLは同じリソースの別名として関連付けます。

初期上限の候補は、HTML本文2MiB、リダイレクト5回、深さ32、ページ数1,000、リンク数10,000です。これらはファイル本体のサイズ上限ではありません。クエリーだけが無限に変わるリンクでも必ず終了し、上限に達した結果を「完全な受信成功」と表示しない契約にします。

表示名と保存先はURLのパス成分から作ります。リンクの表示テキストや`Content-Disposition`を、そのままパスとして使用しません。クエリー違いの同名リソース、パーセント表記、空名、日本語名の衝突を区別し、ローカルの選択ディレクトリ内へ保存します。決定した名前はジョブ内で固定します。

## 設定と転送画面

設定候補は基準URL、開始ページ、ユーザー名、初期ローカルディレクトリ、接続・無通信の期限です。パスワード、TLSの判断、SSH proxyは既存の実行時入力と方針を再利用します。URL自身には認証情報を埋め込みません。

リモート側は一覧の更新、展開、パス移動、受信を提供します。送信、新規フォルダー、名前変更、削除、属性変更はUIとクライアントの両方で拒否します。通常の閲覧は展開されたページを遅延取得し、ディレクトリ受信時に必要な子を探索します。

`Content-Length`がない応答でもストリーミング受信を行い、plan15のジョブへサイズ不明として報告します。切断、キャンセル、HTML解析失敗、HTTPエラーを区別し、未完了ファイルの後始末は共通転送エンジンの契約を使います。

## 段階1：実際のHTMLから範囲内の一覧を作る

Node.jsのローカルHTTPサーバーと、HTMLを取得して候補ノードを出力するネイティブドライバーを用意します。絶対・相対URL、範囲の境界、開始ページ、`base`、フラグメント、クエリー、文字参照、循環のケースをREDにしてから実装します。

この段階で基準URLの設定方法、分類、探索上限を確定します。完了条件は、通信先の記録も含めて範囲外へアクセスせず、循環するHTMLから有限の一覧を得られることです。

## 段階2：読み取り専用クライアントでファイルを受信する

HTTPセッションの必要部分を共通化し、既存WebDAVの動作を確認しながらHTTPクライアントを実装します。ドライバーで一覧取得、単一・再帰受信、サイズ不明の進捗、キャンセル、再接続まで実行します。

リダイレクト後の別名判定、認証失敗、403・404・5xx、HEAD非対応、途中切断、同名ファイルの扱いを検証します。HEADが使えなくてもGETによる受信が成立することが条件です。完了条件は、受信内容の比較と失敗時の後始末が通り、既存WebDAVが動くことです。

## 段階3：設定・ツリー・ジョブへ統合する

接続種別と設定を追加し、保存・継承・入力検証・再接続へ接続します。ツリーの展開と複数選択による受信をplan15のアイコンとジョブで表示します。設定画面だけを先行させず、保存した接続で実際に受信できる単位でコミットします。

完了条件は、画面からHTTPとHTTPSに接続し、循環のある一覧からディレクトリを受信でき、変更操作を選べないことです。

## 段階4：実通信・表示・全体検証

Node.jsの試験サーバーに加え、一般的な静的HTTPサーバーのディレクトリ一覧でも確認します。HTTPSの正常系、既存方式の証明書確認、SSH proxy、探索中の画面閉鎖、進捗表示を検証します。表示を目視確認し、進捗と中止は動画でも確認します。

利用者向け文書に基準URL、開始ページ、読み取り専用、上限時の表示を記載します。`make test`の成功と次の条件を照合して完了とします。

## 最終完了条件

1. HTTP/HTTPSの設定を保存し、基準URLのHTMLから擬似ツリーを閲覧できる。
2. 絶対・相対URLを同じ規則で判定し、リダイレクトや`base`でも許可範囲を広げない。
3. 自己参照、祖先参照、重複、循環、無限のURL生成で探索が継続し続けない。
